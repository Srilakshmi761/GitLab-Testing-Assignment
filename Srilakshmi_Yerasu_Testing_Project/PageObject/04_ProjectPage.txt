*** Test Cases ***

# Positive Tests

Create Blank Project
    Navigate To Project Page    ProjectUrl
    Click on dashboard and then go to project page
    Select Create New Project Option and then select create blank project
    Input Project Name    Valid_ProjectName
    Select project Url
    Submit Create Project Form
    Verify Page Should Contain Project was successfully created


Create Template Project
    Navigate To Project Page    ProjectUrl
    Click on dashboard and then go to project page
    Select Create New Project Option
    Select Create From Template Option
    Choose Any Template
    Input Project Name    Template_Valid_ProjectName
    Select project Url
    Submit Create Project Form
    Verify Page Should Contain The project was successfully imported.


Update Name Of Template Project
    Navigate To Existing Project
    Click on settings (three points on right)
    Click Edit
    Input Project Name    New_ProjectName
    Save Changes
    Verify Page Should Contain Project name was successfully updated.


Delete Template Project
    Navigate To Existing Project
    Click Settings
    Click Delete Project
    Confirm Project Deletion by giving the provided project name
    Click on Yes, delete project
    Verify Project moved to pending deletion
    Verify deleted project is no longer available in project list


# Negative Tests

Create Project With Duplicate Name
    Navigate To Project Page    ProjectUrl
    Select Create Blank Project Option
    Input Project Name    Duplicate_ProjectName
    Submit Create Project Form
    Verify Page Should Contain Project name has already been taken
    The form contains the following errors:
    Project namespace name has already been taken
    Name has already been taken
    Path has already been taken


Create Project Without Giving Name
    Navigate To Project Page    ProjectUrl
    Select Create Blank Project Option
    Input Project Name    Empty
    Submit Create Project Form
    Verify Page Should Contain please fill in this field


Create Project Without Selecting Namespace
    Navigate To Project Page    ProjectUrl
    Select Create Blank Project Option
    Input Project Name    Valid_ProjectName
    Project URL: pick a group or namespace    Empty
    Submit Create Project Form
    Verify Page Should Contain Pick a group or namespace where you want to create this project.


Create Project With Invalid Characters In Name
    Navigate To Project Page    ProjectUrl
    Select Create Blank Project Option
    Input Project Name    @@@###
    Submit Create Project Form
    Verify Page Should Contain Project name must start with a letter, digit, emoji, or underscore.
